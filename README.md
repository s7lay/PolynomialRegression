# Customer Satisfaction Analysis with Polynomial Regression

This repository contains a machine learning workflow demonstrating the implementation of **Linear** and **Polynomial Regression** models using Python and `scikit-learn` to analyze the relationship between customer satisfaction and incentives[cite: 1].

# Project Overview
- **Objective:** Model and visualize non-linear relationships in customer satisfaction datasets.
- **Methods:** 
  - Exploratory Data Analysis (EDA) with Pandas, Matplotlib, and Seaborn[cite: 1].
  - Data Standardization (`StandardScaler`)[cite: 1].
  - Linear Regression baseline model[cite: 1].
  - Polynomial Regression feature transformation (`PolynomialFeatures` degree 2 & 3)[cite: 1].
- **Evaluation Metric:** $R^2$ Score and Mean Squared Error[cite: 1].
